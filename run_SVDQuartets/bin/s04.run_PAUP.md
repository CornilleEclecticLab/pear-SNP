# Title: run PAUP

## First round:

Launch PAUP in srun session
```bash
srun --ntasks=1 --mem-per-cpu=1G --time=00:30:00 --pty bash
./paup/paup4a168_centos64
```

Load the Nexus file in PAUP session, its path is `../output/s03*/$prefix*.nex`
```PAUP
execute your_nexus_file.nex
```

Look at the numbers that PAUP has assigned to the individuals in the loaded Nexus file. Normally, it's the same with `../output/s02*/s02.taxpartitions.txt`
```PAUP
tstatus full
```
Speify the numbers of individuals as outgroup. You could find the useful information in `../output/s02*/s02.*.nex` . Following three lines are equivalent?:
```PAUP
outgroup 1 2 3 

outgroup 1-3

outgroup 1 2-3

```

Simply start the SVDQuartts analysis with PAUP
```PAUP
svdQuartets
```

Exit PAUP
```PAUP
quit
```

Exit the srun session
```bash
exit
```

## Second round:
Lunch srun with **more cpu**
```bash
srun --ntasks=1 --cpus-per-task=6 --mem-per-cpu=2G --pty bash
./paup/paup4168_centos64
```

Load the combined Nexus file `*.parts.nex` in PAUP session
```PAUP
execute ../output/s03.extract_pure_sample_filter_geno_maf_to_nex/*.parts.nex
```

Define outgroup again
```PAUP
outgroup 1-3
```

Run SVDQuartts analysis with PAUP
```PAUP
svdQuartets taxpartition=SPECIES bootstrap=standard nthreads=6
```

Save the result and exit PAUP
```PAUP
saveTrees file='your_nexus_file.svdquartets.tre' supportValues=nodeLabels

quit
```

```bash
exit
```
